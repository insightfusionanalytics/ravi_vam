## Known issues to carry into the reconciliation phase (not fixed here — just flagging what was already known)

- **The 60-day re-entry immunity rule is not in this code either.** Checked directly — same gap as this repo's own `step1.py`/`step2.py`. This repo's work concluded 2026-05-03, three weeks before the rule was finalized on WhatsApp (2026-05-24).
- **This repo's own numbers aren't internally consistent.** `mathematical_audit.md` (2026-04-06) reports Step 1 max drawdown as "~38%." The later `2011_backtest_comparison.md` (2026-05-03) reports -48.43% for what should be the same 2020-2025 window. Something changed in the code between those two dates (there's a `fix: counter issue` commit on 2026-04-09) and the audit was never rerun against it. Don't trust either number without re-verifying against the code as it stands.
- **`results/ravi_vam_v3_databento_results.json` and `results/ravi_vam_v5_databento_results.json`** are present here too, dated 2026-03-20 — but there's no v3/v5 *script* anywhere in this repo that produces them. This is output only, generated by whatever script produced the same v3/v5/v5b family already found in `ravi_vam`'s `backtest_ravi_v5.py`. Still no evidence anywhere — in six client meetings, the WhatsApp thread, or this repo's own transcript-sourced spec doc — that Ravi or Sudhir ever requested or reviewed this family. The 2026-03-20 timestamp is a useful data point: it places this work between meeting 2 (Mar 1) and meeting 3 (Apr 9).
- **The SPXU (Step 3) exit logic is implemented exactly as the client specified it in meeting 4** — VIX < 30 OR SPY reclaims 50-SMA — which is the same rule identified as structurally flawed (it tends to sell the "insurance" right when it's worth the least). This repo didn't invent a fix; it faithfully built what was asked and labeled the gap: `SPXU_EXIT_VIX = 30  # Flag 7: Not discussed. IFA default.`
- **`docs/strategy_extraction.md` flags real, unresolved ambiguities** in the transcripts that this project's own docs (`CLIENT_SOURCE_OF_TRUTH.md`) didn't catch as precisely — most importantly, a direct conflict between two things Ravi said about the re-entry VIX threshold (one quote says VIX < 30, another says VIX < 60), and whether re-entry requires only SPY > 200-SMA or also SPY > 50-SMA. Worth resolving with Ravi directly rather than picking one silently.
